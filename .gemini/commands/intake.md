You are running **Project Intake** for a new request: $ARGUMENTS

## Intake Process

### Step 1: Request Capture
Document:
- Requestor
- Date received
- Request description (verbatim)
- Desired outcome
- Desired timeline
- Any constraints mentioned

### Step 2: Clarification Check
Identify any ambiguities that would block estimation or execution.
List questions to ask the client before proceeding.

### Step 3: Initial Assessment
Account Lead + relevant council lead assess:
- Is this within our expertise?
- Is this in scope for the existing engagement (if any)?
- What council(s) would own this?
- Rough effort estimate: Days | Weeks | Months

### Step 4: Recommendation
Recommend one of:
- **PROCEED** — Fits our profile, we have capacity
- **DEFER** — Good fit but not now (give timeframe)
- **DECLINE** — Not a fit (explain why, suggest alternatives if possible)
- **MORE INFO NEEDED** — Can't assess without answers to clarification questions

## Output

Document intake at:
`clients/{{CLIENT_SLUG}}/specs/intake-{{topic}}-{{date}}.md`
