# 👋 Welcome to the Freelance Developer Harness Discussions

This is the community space for the **Freelance Developer Harness**, a project from [10legs](https://github.com/10legs).

## What this project is

The Freelance Developer Harness is a multi-agent operating system for [Claude Code](https://claude.com/claude-code) that lets a solo developer (or small team) operate like a full creative and technical agency.

Work flows through a **Product Manager** who directs three councils:

- **Creative Council**: Creative Director, Innovation Lead, UX Researcher, UI Designer
- **Technical Council**: Solution Architect, Frontend, Backend, Apple Platform, LLM, Blockchain, Security Reviewer
- **Delivery Council**: Tech Writer, QA, GitHub & Version Control Specialist

Every engagement moves through the same pipeline:

> brief → epic breakdown → research → design → architecture → implementation → QA → security → ship

…with non-negotiable gates at architecture, UX validation, QA, and security review.

Multi-client governance, isolated workspaces, and a search-first protocol keep client work from bleeding across boundaries.

## What to use Discussions for

- **💡 Ideas**: new agents, new gates, workflow improvements, slash commands you'd love to see
- **❓ Q&A**: onboarding a client, kicking off a project, configuring `.env`, customizing agents
- **🛠️ Show & Tell**: custom agents, skills, hooks, council variants, real client setups (scrubbed)
- **🧠 Philosophy**: agent orchestration patterns, human-in-the-loop tradeoffs, gate design, multi-client governance
- **🐛 Pre-issue triage**: not sure if it's a bug or a config mistake? Ask here first

For confirmed bugs and concrete feature requests, please open an **Issue** instead.

## Categories you'll see

- **📣 Announcements**: releases, new agents, breaking changes
- **💡 Ideas**: propose before it becomes an issue
- **🙋 Q&A**: get help using the harness
- **🎨 Show & Tell**: your setups, custom extensions, lessons learned
- **🗣️ General**: everything else

## Ground rules

1. **Be kind.** Small community, opinionated work. Disagreement welcome; condescension isn't.
2. **Show your work.** Repro steps, configs, command output. Context beats vibes.
3. **Search first.** Someone may have already asked.
4. **Respect client confidentiality.** If you're sharing from real client work, scrub the details.
