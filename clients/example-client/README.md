## Project Overview

Acme Corp needs a modern e-commerce storefront to replace their legacy system. We are building a React + Node.js web application with a headless CMS backend, targeting a 3x improvement in page load time and a redesigned checkout flow.

## Goals

1. Replace legacy storefront with a performant, accessible web app
2. Reduce checkout abandonment by 30% through UX improvements
3. Enable the Acme marketing team to manage content without engineering

## Key Constraints

- Budget: $85,000 fixed
- Timeline: Hard deadline of June 30 (holiday season prep)
- Technology: Must integrate with existing Shopify inventory API
- Compliance: PCI-DSS for payment handling
