# Workflow: Client Intake

## Trigger
New prospective client inquiry received.

## Owners
Account Lead (primary), relevant council leads (secondary)

## Process

### Stage 1: Initial Response (24 hours)
- Acknowledge receipt
- Send intake questionnaire (see `templates/client-brief.md`)
- Schedule discovery call

### Stage 2: Discovery Call
- Understand: problem, goals, users, constraints, timeline, budget
- Assess: Is this a fit for our team? Do we have capacity?
- Identify: which councils are involved?

### Stage 3: Fit Assessment
Account Lead + relevant council leads assess:
- Strategic fit: Does this align with our expertise?
- Capacity fit: Do we have bandwidth?
- Cultural fit: Is this a client we want to work with?

Decision: **PROCEED** | **DECLINE** | **DEFER**

### Stage 4: Proposal
If PROCEED:
- Account Lead drafts scope and timeline
- Solution Architect validates technical scope
- Creative Director validates creative scope
- Account Lead presents to client

### Stage 5: Kickoff
If client accepts:
- Run `/onboard-client` command
- Run `/kickoff` command
- Begin discovery phase

## Timeline
Intake to kickoff: 1-2 weeks typical
