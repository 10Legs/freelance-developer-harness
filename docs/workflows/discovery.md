# Workflow: Discovery Phase

## Purpose
Transform a client brief into validated, actionable project foundations across all three councils.

## Duration
Typically 1-3 weeks depending on project scope.

## Parallel Workstreams

### Creative Track
1. Innovation Lead: Problem reframing and ideation
2. UX Researcher: Research planning and execution
3. UX Researcher + Innovation Lead: Insight synthesis
4. UX Researcher: Personas and journey maps
5. Creative Director: Creative brief and direction

### Technical Track
1. Solution Architect: Requirements analysis
2. Solution Architect: Architecture options
3. Solution Architect: Architecture decision + ADRs
4. Security Reviewer: Initial threat model

### Delivery Track
1. Account Lead: Stakeholder mapping
2. Account Lead: Communication cadence setup
3. Account Lead: Milestone plan

## Discovery Gate

Before exiting discovery:
- [ ] UX Research complete and documented
- [ ] Personas and journey maps finalized
- [ ] Architecture approved (ADRs written)
- [ ] Security threat model complete
- [ ] Creative brief approved
- [ ] Milestone plan agreed with client

## Output
Discovery Summary document at `clients/{{CLIENT_SLUG}}/specs/discovery-summary.md`
