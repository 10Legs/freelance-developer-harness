# Pattern: UX Audit

**Category:** Design
**Owner:** UX Researcher
**Last Updated:** [Date]

## When to Use

When taking on a client with an existing product that needs improvement, or before starting a redesign project.

## UX Audit Structure

### 1. Heuristic Evaluation (Nielsen's 10 Heuristics)
Score each heuristic 0-4 (0=not a problem, 4=usability catastrophe):

1. Visibility of system status
2. Match between system and real world
3. User control and freedom
4. Consistency and standards
5. Error prevention
6. Recognition rather than recall
7. Flexibility and efficiency of use
8. Aesthetic and minimalist design
9. Help users recognize, diagnose, recover from errors
10. Help and documentation

### 2. User Flow Analysis
Map every critical user journey and identify:
- Drop-off points
- Confusion points
- Missing functionality
- Unnecessary steps

### 3. Accessibility Assessment
- Automated scan (axe, Lighthouse)
- Manual keyboard navigation test
- Color contrast check
- Screen reader walkthrough

### 4. Competitive Benchmarking
Compare 3 competitors/analogues on:
- Onboarding flow
- Core task completion
- Mobile experience
- Innovative differentiators

### 5. Findings Report

Severity classification:
- **Critical:** Prevents task completion
- **High:** Significantly impairs task completion
- **Medium:** Causes frustration but task completable
- **Low:** Minor improvement opportunity

## Output

UX Audit Report with:
- Executive summary (3-5 key findings)
- Severity-ranked issue list
- Recommended priorities for improvement
- Quick wins (low effort, high impact)
- Strategic redesign recommendations
