# Pattern: Ideation Session

**Category:** Innovation
**Owner:** Innovation Lead
**Last Updated:** [Date]

## When to Use

When a client challenge requires creative problem-solving beyond conventional approaches. Best used at project start or when a project is stuck.

## Session Preparation

Before the session:
1. Frame the challenge clearly (one problem statement)
2. Share relevant user research with participants
3. Set context: constraints, success criteria, timeline
4. Warm up: quick unrelated creative exercise

## Session Format (60 minutes)

### Part 1: Diverge (20 minutes)
Generate ideas without judgment:
- Set a volume target (e.g., 20 ideas)
- Use multiple techniques: SCAMPER, Analogies, Worst Possible Idea (invert it)
- Build on each other's ideas
- No criticism during this phase

### Part 2: Cluster (10 minutes)
Group related ideas:
- Look for themes
- Identify surprising combinations
- Name each cluster

### Part 3: Converge (20 minutes)
Select most promising:
- Dot voting (each participant: 3 votes)
- Top clusters get deeper development
- Apply: Desirable? Viable? Feasible?

### Part 4: Develop (10 minutes)
Sketch top 3-5 concepts:
- One-sentence description
- Key user benefit
- Key risk

## Output

Ideation session document with:
- Original challenge statement
- All ideas generated (for the record)
- Selected top concepts with development
- Recommended next steps (prototype? research? ADR?)

## Tips

- Diverse perspectives generate better ideas (include client stakeholders)
- The worst idea can spark the best idea — don't filter early
- Document everything, even bad ideas — they may become good later
- Set a timer for each phase — urgency drives creativity
