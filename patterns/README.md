# Patterns Library

This library contains reusable patterns across three domains. Always search here before creating something new.

## Search Protocol (Mandatory)

Before implementing anything:
1. Check this README for relevant patterns
2. Read the specific pattern file
3. Adapt to your context (don't copy blindly)
4. If you create a new pattern, document it here

## Contributing a New Pattern

When you identify a reusable pattern:
1. Create a file in the appropriate directory
2. Follow the pattern template format
3. Add it to this README table
4. Get Solution Architect (technical) or Creative Director (design) sign-off
